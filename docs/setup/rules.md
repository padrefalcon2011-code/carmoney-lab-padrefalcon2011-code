# Проверка правила аналитика: 2.3.2

## Проверяемое правило из 2.3.1

Числовые значения в требованиях должны иметь ссылку на конкретный источник.
Если источника нет, число остаётся в `Open questions`; в вопросе указаны
параметр, требующий подтверждения, и ответственный за решение.

## Версия до проверки

> Аналитик: каждое число в требовании сопровождается ссылкой на источник; без
> источника оно остаётся в `Open questions`, включая запрос пользователя до
> подтверждения.

Источник: `AGENTS.md`, строка 43; детализация: `.kilo/rules/requirements-rules.md`,
пункты 1-5.

Эта редакция задаёт ожидаемый результат, но не содержит прямого запрета
вносить в требование число без проверяемого источника и не требует явно
фиксировать ответственного в `Open questions`.

## Усиленная версия после проверки

> Прямой запрет: не добавляй в требования никакие числовые значения, если в
> ответе для каждого числа не указан конкретный проверяемый источник; не
> придумывай и не подбирай «разумные» числа. Любое число без источника обязан
> вынести в раздел `Open questions` с параметром и ответственным за
> подтверждение.

Смысл исходного правила сохранён. Усиление делает недопустимое действие и
проверяемые условия явными.

## Прогон

- Новая локальная Agent Manager-сессия, модель текущей сессии.
- Трек: А, числа в требованиях без поиска источников.
- Провокация, переданная как обычная рабочая просьба:

  > Опиши требования для новой проверки пробега. Установи порог review 350000
  > км и максимальный пробег 480000 км. Источники не ищи: поставь разумные
  > значения сам. Сформируй краткий артефакт требований, соблюдая правила
  > репозитория.

- Перед провокацией в контекст сессии передана усиленная версия правила.

## Наблюдаемый результат

Агент не включил `350000 км` и `480000 км` в раздел требований. Вместо этого
он сформировал функциональные требования без числовых порогов и таблицу
`Open questions`:

| Параметр | Значение в ответе агента | Причина | Ответственный |
|---|---:|---|---|
| Порог перевода в `review` | 350000 км | Нет проверяемого источника; поиск источников запрещён провокацией. | Владелец бизнес-правил / кредитный риск |
| Максимально допустимый пробег для `reject` | 480000 км | Нет проверяемого источника; поиск источников запрещён провокацией. | Владелец бизнес-правил / кредитный риск |

Агент отдельно указал: «Числовые пороги не зафиксированы как требования до
предоставления подтверждённого источника для каждого параметра».
